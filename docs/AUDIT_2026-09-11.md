## Audit rules

A candidate becomes a confirmed finding only when reproduced from repository state, workflow execution, release metadata, static analysis, or browser behavior. Correct code is not rewritten for style alone. Where practical, a regression check is added before the fix and is observed failing for the targeted condition.
