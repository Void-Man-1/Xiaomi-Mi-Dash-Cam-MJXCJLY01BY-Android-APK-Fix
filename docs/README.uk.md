# Xiaomi Mi Dash Cam MJXCJLY01BY — APK для Android 8.1–16

Це неофіційна виправлена версія застосунку **Mi Dash Cam для європейської камери Xiaomi `MJXCJLY01BY`**, адаптована до сучасних версій Android і HyperOS.

Проєкт призначений для випадків, коли старий застосунок Mi Dash Cam не встановлюється на Android 15/16, неправильно підключається до камери через Wi-Fi, показує чорний екран замість перегляду в реальному часі, зависає, не завантажує записи або вимагає застарілий обліковий запис Mi.

Версія 2.0.0 працює локально без облікового запису Mi. Фінальний підписаний APK повністю перевірено з реальною камерою `MJXCJLY01BY` на **Poco F6 з Android 16 / HyperOS 3**. Підключення та повторне підключення, перегляд у реальному часі, список і мініатюри записів, завантаження та відтворення успішно пройшли перевірку.
