# Xiaomi Mi Dash Cam MJXCJLY01BY — APK für Android 8.1–16

Dies ist eine inoffizielle, angepasste Version der **Mi Dash Cam-App für die europäische Xiaomi-Kamera `MJXCJLY01BY`**, die für aktuelle Android-Versionen und HyperOS kompatibel gemacht wurde.

Das Projekt richtet sich an Nutzer, bei denen sich die alte Mi Dash Cam-App unter Android 15/16 nicht mehr installieren lässt, keine stabile WLAN-Verbindung zur Kamera herstellt, statt der Live-Vorschau nur ein schwarzes Bild zeigt, hängen bleibt, Aufnahmen nicht lädt oder ein veraltetes Mi-Konto verlangt.

Version 2.0.0 funktioniert lokal ohne Mi-Konto. Die final signierte APK wurde vollständig mit einer echten `MJXCJLY01BY` auf einem **Poco F6 mit Android 16 / HyperOS 3** getestet. Verbindung und erneute Verbindung, Live-Vorschau, Aufnahmeliste und Vorschaubilder, Download sowie Wiedergabe wurden erfolgreich geprüft.
