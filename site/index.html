What this build fixes

Compatibility fixes for current Android versions.

The changes are limited to functions that stopped working correctly on newer phones; they do not redesign the camera itself.

↧

Installs on Android 15 and 16

Updates the app’s Android and CPU compatibility so it installs normally on Android 15 and 16.

◉

Live preview restored

Repairs the legacy stream path and uses RTSP over TCP. Visible live video was verified with the physical camera.

◎

Local use without a Mi account

The app starts with an Offline account and works directly with the camera without the obsolete Xiaomi sign-in flow.

▤

Recordings and downloads

The recording list, thumbnails, downloads and playback were tested with the camera.

⌁

ARM64 and 16 KiB support

Adds ARM64 and 16 KiB page-size compatibility while retaining ARMv7 support for older devices.

Help works offline

Unavailable web help pages were replaced with bundled guidance and manuals that remain available offline.

Install in four steps.

The app communicates directly with the dashcam over its Wi-Fi network. Camera transfers do not use mobile data.

Open Mi Dash Cam

Add the camera, confirm the live view, then browse or download recordings locally.

FAQ

Before you install

Is this an official Xiaomi update?

No. This is an independent compatibility project for companion software that is no longer maintained. Xiaomi, Mi, Mijia and 70mai names belong to their respective owners.

Does it work on Android 16?

Yes, on the tested setup. Version 2.0.0 completed a full physical-camera test on a Poco F6 running Android 16 / HyperOS 3.

Does it work with Mi Dash Cam 1S (MJXCJLY02BY)?

No compatibility claim is made for MJXCJLY02BY. Check the model label and use this project only for MJXCJLY01BY EU.

Why is there a checksum?

A SHA-256 checksum lets you confirm that the APK you downloaded matches the file published by this project. Android also requires APKs to be signed; this build uses the project’s release key, not Xiaomi’s original key.

Which Android versions were actually tested?

Physical or emulator testing is documented for Android 8.1, 9 and 12 through 16. Android 10–11 are not currently claimed as tested.
