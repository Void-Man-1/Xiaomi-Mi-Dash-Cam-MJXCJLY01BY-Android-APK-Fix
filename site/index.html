FAQ

Before you install

Is this an official Xiaomi update?

No. This is an independent preservation/compatibility project for abandoned companion software. Xiaomi, Mi, Mijia and 70mai names belong to their respective owners.

Does it work on Android 16?

Yes for the tested target. The exact 2.0.0 release completed a full physical-camera test on a Poco F6 running Android 16 / HyperOS 3.

Does it work with Mi Dash Cam 1S (MJXCJLY02BY)?

No compatibility claim is made for MJXCJLY02BY. Check the model label and use this project only for MJXCJLY01BY EU.

Why is there a checksum?

A SHA-256 checksum lets you confirm the APK you downloaded is exactly the artifact published by this repository. Android also requires APKs to be signed; this compatibility build is release-signed by the project, not by Xiaomi’s original key.

Which Android versions were actually tested?

Physical or emulator testing is documented for Android 8.1, 9 and 12 through 16. Android 10–11 are not currently claimed as tested.
